# Feedback inbox

Working notes for changes to the thesis site. Notes arrive here from
the site itself: the ✎ button on any page of the local preview (tags
the page automatically), or the form on the Feedback appendix page.
Editing this file by hand works too — one `###` header per page under
**Open**, one bullet per change.

Telling Claude "apply my feedback" (or `/thesis-feedback`) applies
every open item to the source files, re-renders, and moves the items to
the Applied log below.

This file is intentionally outside the site's public render — the
Feedback page reads it live through the local server, so nothing here
ever appears on the published site.
